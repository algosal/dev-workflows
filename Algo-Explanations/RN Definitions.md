| Feature / Library                             | One-liner Explanation                                                          |
| --------------------------------------------- | ------------------------------------------------------------------------------ |
| **React Native**                              | Framework for building cross-platform mobile apps using React.                 |
| **React**                                     | Core library for building UI components.                                       |
| **React DOM**                                 | Bridges React to web, usually unused in RN but needed for some tooling.        |
| **@react-native/new-app-screen**              | Provides default starter screens for new RN apps.                              |
| **@react-navigation/native**                  | Core navigation container for React Native apps.                               |
| **@react-navigation/native-stack**            | Stack-based navigation with native performance.                                |
| **react-native-gesture-handler**              | Handles gestures like taps, swipes, and pan on RN views efficiently.           |
| **react-native-reanimated**                   | High-performance animations, replaces JS animations with native threads.       |
| **react-native-safe-area-context**            | Handles notches, status bars, and safe display areas on devices.               |
| **react-native-screens**                      | Optimizes navigation by using native screen components instead of RN views.    |
| **Fabric (RN)**                               | New React Native rendering engine, modernizes UI pipeline for faster updates.  |
| **Kotlin in RN**                              | Language used for native Android modules in React Native.                      |
| **Gradle**                                    | Android build system that compiles RN and its native modules.                  |
| **@types/react / @types/react-test-renderer** | TypeScript definitions for React and test rendering.                           |
| **react-test-renderer**                       | Allows testing React components outside the device/emulator.                   |
| **Babel**                                     | Transpiles modern JS/TS to older JS that can run in RN environments.           |
| **ESLint / Prettier**                         | Code quality and formatting tools.                                             |
| **Jest**                                      | Test runner for unit and snapshot testing.                                     |
| **`usesCleartextTraffic`**                    | Android manifest flag to allow HTTP traffic during development.                |
| **Legacy Peer Deps (`--legacy-peer-deps`)**   | Installs dependencies ignoring peer version conflicts, avoids ERESOLVE errors. |
